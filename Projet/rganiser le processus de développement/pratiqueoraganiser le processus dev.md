# Organiser le processus de développement

## 1. Cadrer

1. Consulter les catégories
   Exemple : afficher les catégories dans un tableau.

2. Ajouter une catégorie
   Exemple : ajouter la catégorie « Sport ».

3. Modifier une catégorie
   Exemple : modifier « Sport » en « Football ».

4. Supprimer une catégorie
   Exemple : supprimer la catégorie « Football ».

---

## 2. Concevoir

1. Définir les données
   Exemple : `id`, `nom`, `couleur`, `icone`.

2. Définir l’API
   Exemple : `GET`, `POST`, `PUT`, `DELETE`.

3. Préparer l’interface
   Exemple : formulaire + tableau.

---

## 3. Développer

1. Créer le formulaire
   Exemple : formulaire pour ajouter une catégorie.

2. Créer l’API
   Exemple : endpoint `POST /categories`.

3. Ajouter le JavaScript
   Exemple : utiliser `fetch()` pour envoyer les données.

---

## 4. Tester

1. Tester l’affichage
   Exemple : vérifier que les catégories apparaissent.

2. Tester l’ajout
   Exemple : ajouter « Sport ».

3. Tester la modification
   Exemple : modifier « Sport » en « Football ».

4. Tester la suppression
   Exemple : supprimer « Football ».

5. Tester les erreurs
   Exemple : essayer d’ajouter une catégorie sans nom.

---

## 5. Valider

1. Vérifier l’affichage
   Exemple : toutes les catégories sont visibles.

2. Vérifier l’ajout
   Exemple : une nouvelle catégorie est bien ajoutée.

3. Vérifier la modification
   Exemple : les informations sont bien modifiées.

4. Vérifier la suppression
   Exemple : la catégorie supprimée disparaît.

5. Vérifier le besoin final
   Exemple : toutes les fonctionnalités demandées fonctionnent.
